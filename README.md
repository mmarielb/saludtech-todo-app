# Todo App - Rails 7 + PostgreSQL + Tailwind

## Configuración del proyecto

Este proyecto es un sistema simple de gestión de tareas (TODO list) usando Rails 7, PostgreSQL y Tailwind.

### 1. Requisitos

- Ruby 3.2.2
- Rails 7.1.x
- PostgreSQL 9.3+
- Bundler (`gem install bundler`)

### 2. Variables de entorno

Crea un archivo `.env` en la raíz del proyecto con las siguientes variables:

```dotenv
DB_USERNAME=postgres
DB_PASSWORD=postgres
DB_HOST=localhost
DB_PORT=5432
